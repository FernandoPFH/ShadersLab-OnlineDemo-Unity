# ShadersLab-OnlineDemo-Unity

![](/Imagems/TelaInicial.png)
Criação de uma demo online para observar uma série de shaders diferentes em display.

## Link Para Teste

[Clique Aqui](https://fernandopfh.github.io/ShadersLab-OnlineDemo-Unity/)

## How To Use As A Package:

1. Open the Package Manager window, if it’s not already open.
2. Open the Add (+) menu in the Package Manager’s toolbar.
3. The options for installing packages appear.
4. Select Install package from git URL from the install menu. A text box and an Install button appear.
5. Enter the Git URL bellow in the text box
```
https://github.com/FernandoPFH/ShadersLab-OnlineDemo-Unity.git?path=ShadersLab/Assets/FernandoPFH_ShadersPack
```
6. All shaders will be in the folder `Packages/FernandoPFH_ShadersPack/Shaders`

## Como Usar Como Um Pacote:

1. Abra a janela do Package Manager (Gerenciador de Pacotes), se ainda não estiver aberta.
2. Abra o menu Adicionar (+) na barra de ferramentas do Package Manager.
3. As opções para instalar pacotes aparecem.
4. Selecione Install package from git URL (Instalar pacote a partir da URL do git) no menu de instalação. Uma caixa de texto e um botão Install (Instalar) aparecem.
5. Insira a URL do Git abaixo na caixa de texto.
```
https://github.com/FernandoPFH/ShadersLab-OnlineDemo-Unity.git?path=ShadersLab/Assets/FernandoPFH_ShadersPack
```
6. Todos os shader estarão na pasta `Packages/FernandoPFH_ShadersPack/Shaders`
